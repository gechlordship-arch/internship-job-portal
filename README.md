# CareerBridge — Internship and Job Portal

CareerBridge is a web application designed to connect students with internship and job opportunities and help employers manage job postings and applications.

## Features

- Student and employer accounts
- Internship and job listings
- Search and filter opportunities
- Online job applications
- Application status tracking
- Separate dashboards for students and employers

## Technology Stack

**Frontend**
- React
- Vite
- JavaScript
- CSS

**Backend**
- Node.js
- Express.js

**Database**
- PostgreSQL

## Project Structure

```text
internship-job-portal/
├── client/       # React frontend
├── server/       # Express backend
├── .gitignore
├── package.json
└── package-lock.json
```

## Getting Started

1. Clone this repository.
2. Install the frontend and backend dependencies.
3. Configure your local environment variables.
4. Create the PostgreSQL database and apply the database schema.
5. Start the backend and frontend development servers.

See the client and server directories for their respective configuration files.

## Environment Variables

Create local `.env` files as required by the client and server configurations. Never commit passwords, database credentials, or other secrets.
